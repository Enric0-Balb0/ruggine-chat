## 🎨 Linee Guida per la Cattura

### Qualità e Formato
- **Formato**: PNG per qualità migliore
- **Risoluzione minima**: 1200x800px per screenshot full-screen
- **DPI**: 96 DPI per web, 150+ DPI per stampa
- **Compressione**: Minima per mantenere leggibilità del testo

### Contenuto
- **Dati realistici**: Usa nomi, email, gruppi credibili ma generici
- **Privacy**: Non usare dati reali o sensibili
- **Completezza**: Mostra tutte le funzionalità descritte nel testo
- **Consistenza**: Stesso stile e tema attraverso tutti gli screenshot

### Post-Processing
- **Crop**: Rimuovi parti non necessarie mantenendo il contesto
- **Annotazioni**: Aggiungi frecce o cerchi se necessario per evidenziare elementi
- **Ridimensionamento**: Ottimizza dimensioni per web (~800px larghezza max)
- **Watermark**: Considera aggiungere watermark discreto del progetto

### Organizzazione File
- **Nomi**: Usa esattamente i nomi indicati (01-registrazione.png, etc.)
- **Backup**: Mantieni copie ad alta risoluzione
- **Versioning**: Se aggiorni, mantieni versioni precedenti

## 🔄 Aggiornamenti

Quando aggiorni l'interfaccia dell'app:
1. Verifica quali screenshot sono obsoleti
2. Ri-cattura solo quelli modificati
3. Mantieni consistenza di stile con gli altri
4. Aggiorna questo README se necessario

## 📏 Dimensioni Consigliate per Web

Per ottimizzare il caricamento nel manuale:
- **Screenshot full-page**: 1200x800px → ridimensiona a 800x533px
- **Modals/Dialogs**: Mantieni dimensioni originali se < 600px larghezza
- **Confronti side-by-side**: Max 1000px larghezza totale
